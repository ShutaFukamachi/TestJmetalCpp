# 019: FBI(B5)統合はコスト目的を破壊し A1 に劣位で失敗。真の最適は 125 と確定

## 発生日
2026-07-22（018 の topological バグ修正後の A/B データ分析）

## 結論（先に）
- **真の最適 makespan は 125**（139 ではない）。
- **FBI 統合は失敗**。makespan で A1(優先規則シード)を上回れず、
  かつ **コスト目的を全試行で +8〜9% 悪化**させる（＝A1 に厳密劣位）。

## 「真の最適 = 125」の三重確認（j309_1 RR050 RV0）
1. MIP の ms=125 スケジュールを feasibility checker に通す → **prec=0 res=0（実行可能）**。
2. capacity_t を MIP と NSGA/FBI ランナーでバイト比較 → **完全一致**（017 の不一致なし）。
3. RV0 の全 (k,t) で **最小容量=7 > 0** → cap=0 スロットなし → 016 の MIP バグは無関係。
4. さらに **NSGA-II(A1+FBI) 自身が feasible な ms=125 を独立再現**（10試行中1回, prec=0 res=0）。
→ 125 は実行可能かつ厳密解。**139 は単なるヒューリスティックのプラトー**、最適ではない。
   （018 の 117/125 は topological バグの虚数。139 と混同しないこと。）

## FBI 失敗の根拠データ（10試行/条件, 4戦略, 120k evals, RR050 RV0）
| 条件 | ms* (10試行) | ms*平均 | minCost 下限 |
|---|---|---|---|
| OFF baseline | 159×10 | 159 | ~413,000 |
| A1 優先規則シード | 139×10 | 139 | ~413,500 |
| FBI 単独 | 139×7, 159×3 | ~147 | ~449,500 (+8.7%) |
| A1+FBI | 125×1, 139×9 | ~137 | ~450,500 (+9.0%) |

- A1 単独が **最も安定（10/10 で 139）かつ低コスト**維持。
- FBI 単独は makespan 不安定（3/10 は baseline 159 のまま）、A1 に負ける。
- **FBI は minCost を +8〜9% 悪化（全試行で 100% 再現）**＝決定的な失敗サイン。
- FBI 単独で cost@ms*=485822 が4試行同値 → 圧縮スケジュール1点への収束（多様性喪失）。

## 根本原因（RCPSP_Problem_MaxShift.cpp:216-234, 363-372）
1. FBI を evaluate() 内で全解に適用し、**makespan が厳密改善したときだけ**採用、
   採用時は **最早実行可能（左詰め圧縮）**スケジュールで startArr を上書きしコスト再計算。
2. **時変コストでは「最早 ≠ 最安」**。左詰め圧縮は MaxShift 遺伝子が意図的に選んだ
   「安い後半スロットへの遅延」を破壊し、低コスト解を消滅させる → 前面のコスト側が崩壊。
3. 改善は phenotype(startTimes_)/目的値のみ更新で **遺伝子(max_shift)へ書き戻さない
   （非遺伝的=Baldwin型）**。GA は毎世代 未justify のスケジュールを再生成し、FBI 計算を
   毎評価やり直すだけで累積せず、計算コストだけ増える。

## 教訓
- **双目的(makespan,cost)に単目的(makespan)ローカルサーチを全解一律適用してはいけない。**
  片方の目的を最適化する justification は、もう片方の目的の探索多様性を破壊する。
- 手法評価は best だけでなく **mean/worst と両目的（特に minCost 下限）で**見る。
  best だけ見ると FBI が 125 を1回出したのを過大評価する（実際は 1/10 の運）。
- A1(優先規則シード) は安価・安定・低コストで、FBI より厳密に優れる。
  **効果のない/劣位の手法は即やめる**（feedback_drop_ineffective 準拠）。次のアイデアは
  「遺伝子書き戻し(Lamarck型)」や「コスト保存 justification」だが、まずはユーザー提示待ち。
