# 007: Branch and Bound（分枝限定法）はこのプロジェクトで無視する

## 発生日
2026-06-09

## バグの概要
README に Branch and Bound の記述が含まれていたが，本プロジェクトのスコープ外であるとユーザーから明示的に指摘された。

## 根本原因
過去のセッションで BnB の実装・説明を追加したことがあったが，本プロジェクトは NSGA-II による 2 エンコーディング比較が主目的であり，BnB は対象外。

## 修正内容
- README.md から「Branch and Bound」セクションおよび関連記述を全て削除
- `src/metaheuristics/` のディレクトリ説明から「Branch and Bound」の言及を削除

## 教訓
- **Branch and Bound（分枝限定法）はこのプロジェクトで実装・記述・提案しない**
- README やコメントで BnB に言及しない
- ユーザーから BnB 関連の作業を明示的に依頼されない限り，一切関与しない
