## 課題1: 休暇ありの中間部 — λ 遺伝子（2026-10-28 15:55）
- 診断（rv1_diag.py、dl r1、j30 全48）: RV1 の中間部の鎖上の遅らせ（MIP 258、NSGA 285 コマ）は、ほぼすべて休暇日をまたぐ長い遅らせ
  （1回 約60コマ、休暇 約4回）で、1コマあたりの節約は 28（休暇をまたがない遅らせは 約280）。鎖1本で休暇をまたぐ回数は
  MIP 17.8、NSGA 19.7 で、差の約2回 × 14日 ≈ 27コマが工期差（27コマ）にほぼ一致。資源2・3の価格は約12コマ周期で大きく上下する。
  → 「窓の中で最安」を選ぶので、わずかな節約のために何周期も先へ飛ぶ遅らせが鎖に入る。
- 仮説 H-λ: 配置を「コスト + λ_j ×（遅らせたコマ数）」の最小で選ぶ（λ_j = 0.2 u^2 × t_mak での1コマあたりのコスト、u は個体ごとの遺伝子
  vars[n+n-1]、子ごとに確率 0.2 で変異）と、節約の小さい長い飛びが減り、RV1 の中間部が縮む。λ=0 の個体はコスト端を担当できる。
- 実行: dllam = dl + --lambda-gene --lambda-mut 0.2（NSGA1028.exe）。j30 全48 × 5回、j120（20×3回）。
- 基準（dl と比べる）: (d) j30 中間部の5回平均 < dl の5回の最小値（7.70%）
  (e) j30 工期端の5回平均 ≥ dl の最小値（222） (f) HV 差（dllam − dl）の平均 + 2SE ≥ 0 を j30・j120 の両方で
- 記述: RV0/RV1 別の中間部（mid_delay_diag.py の対の差）、鎖上で休暇をまたぐ回数（rv1_diag.py）。

## 課題2: コスト端と中間部の両立 — コスト島（2026-10-28 15:55）

  コスト端へ引っ張る。一方、工期島は「別の小さな集団で端だけを探し、集団の最良を超えた1体だけを送る」ので中間部を薄くしなかった。

  30世代停滞で停止）なら、中間部を薄くせずにコスト端だけを良くできる。
- 実行: dlci = dl + --cost-island 20（NSGA1028.exe）。j30 全48 × 5回、j120（20×3回）。
- 基準（dl と比べる）: (g) j30 コスト端の差の5回平均 < dl の5回の最小値（0.159%）
  (h) j30 中間部の5回平均 ≤ dl の5回の最大値（8.22%） (i) HV 差の平均 + 2SE ≥ 0 を j30・j120 の両方で
