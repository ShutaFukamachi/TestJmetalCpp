# 事前登録: 複数回実行による確認（2026-10-16、実行前に固定。結果を見て変更しない）

## 目的
10/14 の1回実行で有望だった「工期島（停滞で停止）＋部分再構築」（isrgp）が、乱数のばらつきを超えて
現在の手法（base）より良いかを確かめる。工期島を止めない版（isrg）も j30 で比べ、止めることの損得を測る。

## 実行
- j30: 全48インスタンス × 6条件、base / isrgp / isrg を各5回（タグ t1016_{base,isrgp,isrg}_r1〜r5）
- j120: j1201_1〜j12020_1 の20インスタンス × 6条件、base / isrgp を各3回（タグ t1016_{base,isrgp}_r1〜r3）
- 設定: isrgp = `--island 20 --regen 0.1 --island-patience 30`、isrg = `--island 20 --regen 0.1`。
  すべて `--p1-only --cost-dir=costs_ext --trace`。評価回数は従来どおり 50,000/戦略 × 4戦略。

## 指標
1. 工期端（j30）: MIP の最小工期と一致した条件数（/240）、10%以上ずれた条件数。各回の値と5回の平均。
2. 探索の寄与（j30）: 初期集団で MIP の最小工期に届かなかった条件のうち、最終的に届いた割合。
3. 前線全体: 条件ごとに、全手法・全回と MIP を合わせて正規化した共通 HV を求め、手法ごとに回の平均をとる。
   差（isrgp − base）を条件で平均し、±2SE を付ける。
4. 中間部（j30）: MIP の各点と同じかより安いコストでの工期の差（平均）。
5. j120: RR000_RV0 の PSPLIB 最良既知値との差（20インスタンス、回の平均）、HV の差（3 と同じ方法）。
6. j309_1 RR050_RV0 で 125 に届いた回数（5回中）。

## 判定（isrgp を以後の標準設定にするか）
- 採用: 次をすべて満たす
  (a) j30 の MIP 一致数の5回平均が、base の5回の最大値より大きい
  (b) j30 の HV 差の平均 − 2SE ≥ 0 に届かなくても、平均 + 2SE ≥ 0（＝悪化していると言えない）
  (c) j120 の最良既知値との差の平均が base より小さい
  (d) j120 の HV 差の平均 + 2SE ≥ 0（悪化していると言えない）
- 不採用: (a)〜(d) のどれかを満たさない。特定のインスタンスを除いて初めて満たす場合も不採用。
- isrg と isrgp の比較は採否には使わず、「止めると工期端がどれだけ戻るか」の記述にとどめる。
